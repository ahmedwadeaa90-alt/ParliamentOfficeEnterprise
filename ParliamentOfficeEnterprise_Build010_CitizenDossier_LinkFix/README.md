# Parliament Office Enterprise

منظومة الإدارة البرلمانية الذكية لإدارة الصادر والوارد والمواطنين والمتابعة والربط والتقارير ومنجزات النائب.

## Build 009 Stable

هذا الإصدار يركز على الاستقرار قبل العودة إلى OCR أو الذكاء الاصطناعي.

### أهم التغييرات
- إزالة OCR مؤقتاً.
- تفعيل الضغط المزدوج على الصادر والوارد والمواطنين.
- تفعيل قائمة الزر الأيمن للجداول الأساسية.
- نقل الجهات، المستخدمين، والنسخ الاحتياطي إلى تبويب الإعدادات.
- إضافة وحدة منجزات النائب.
- إضافة تقرير منجز HTML حسب الفترة.

## التشغيل
افتح ملف:

`ParliamentOfficeEnterprise.sln`

ثم شغّل مشروع `ParliamentOffice.UI` من Visual Studio.

بيانات الدخول الافتراضية:

- المستخدم: `admin`
- كلمة المرور: `1234`
